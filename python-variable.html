变量

变量是 Python 程序里给数据贴上的名字。先理解变量，后面的条件分支、循环和函数才会顺起来。

一句话理解

变量就是一个名字，用来指向程序正在使用的数据。

关键词

变量名

给数据起的名字，例如 age、name、score。

基础

值

变量指向的具体数据，可以是数字、文字、列表等。

数据

赋值

用 = 把右边的数据交给左边的变量名。

=

代码例子

name = "Yuki"
age = 20
score = 85

print(name)
print(age + 1)
print(score >= 80)

代码怎么读

  • name = "Yuki"：把文字 Yuki 保存到变量 name 里。
  • age = 20：把数字 20 保存到变量 age 里。
  • print(age + 1)：先取出 age 的值，再加 1，最后显示结果。

易混点

变量不是盒子本身

更准确地说，变量名是指向数据的名字。入门阶段可以先把它想象成贴标签的盒子。

等号不是数学等于

Python 里的 = 是赋值，意思是“把右边交给左边”。比较是否相等要用 ==。

记忆宫殿画面

想象一个仓库管理员给盒子贴标签：贴着 name 的盒子里放文字，贴着 age 的盒子里放数字。程序要用数据时，就按标签去找。
