Python 基础

从变量、条件分支、循环和函数开始，把 Python 基础知识整理成可以复习、可以关联、可以继续扩展的学习路径。

一句话理解

Python 是一种语法简单、适合入门、自动化处理和项目实战的编程语言。

学习路径

变量 → 条件分支 → 循环 → 函数 → 文件处理 → 项目实战

知识点卡片

变量

用名字保存数据，例如姓名、数字、计算结果，是程序记住信息的基础。

入门 数据

条件分支

用 if / elif / else 根据条件选择不同处理，让程序能够做判断。

if 逻辑

循环

用 for 或 while 重复执行处理，适合遍历列表、重复计算和批量操作。

for while

函数

把一段处理打包成可以重复调用的模块，重点理解参数、return 和调用位置。

def return

文件处理

读取和写入文件，把程序运行结果保存下来，也能处理外部数据。
