# v1.1 iBut 原始资料逐章补全计划

## 1. v1.1 目标

v1.1 的目标是把原始 iBut 学习资料逐章补进现有数据文件，同时保持页面功能稳定。

- 不改页面功能
- 不改 `app.js` 逻辑
- 只扩充 `content-data.js`
- 将原始资料逐章结构化导入
- 保留每章的中日英关键词、考试题眼、易混淆点和模拟题

## 2. 当前 v1.0 MVP 状态

当前 v1.0 已经具备基础学习网页能力：

- 7章导航
- 每章基础内容
- 搜索
- 中日英关键词表
- 题眼速查
- 模拟题
- 已读进度
- 移动端适配

但当前内容仍是 MVP 骨架，不是完整资料库。v1.1 的重点是逐章补全资料，而不是增加新功能。

## 3. v1.1 不做的事

v1.1 明确不做以下内容：

- 不做错题本
- 不做随机出题
- 不做用户登录
- 不做数据库
- 不做 AI 自动生成
- 不做暗色模式
- 不做统计图表
- 不改页面布局
- 不改 `app.js`

## 5. 每章导入格式

每一章导入时，都必须补充以下四类数据。

### 5.1 studySections

每个小节必须包含：

- `id`
- `chapter`
- `title`
- `category`
- `goal`
- `jpKeywords`
- `explanation`
- `scenario`
- `examHints`
- `confusion`
- `summary`

### 5.2 terms

每个术语必须包含：

- `id`
- `sectionId`
- `chapter`
- `jp`
- `reading`
- `zh`
- `en`
- `hint`

### 5.3 examHints

每个题眼必须包含：

- `id`
- `chapter`
- `keyword`
- `answer`
- `note`

### 5.4 quizzes

每道题必须包含：

- `id`
- `chapter`
- `question`
- `answer`
- `explanation`
- `hint`

## 6. 每批导入后的验收标准

每批导入后必须检查：

1. `content-data.js` 没有语法错误
2. 页面能正常打开
3. 当前章节能在导航中显示
4. 当前章节有 `studySections`
5. 当前章节有 `terms`
6. 当前章节有 `examHints`
7. 当前章节有 `quizzes`
8. `terms.sectionId` 能对应到 `studySections.id`
9. 搜索日语、中文、英语关键词都能找到内容
10. Console 没有红色报错

## 8. 风险控制

- 不要一次性补全部章节
- 每次只补一章或一批
- 不要改变字段名
- 不要让 `sectionId` 失配
- 不要重复 `id`
- 不要把长篇正文直接塞成一整段
- 每个 `studySection` 应该短而清楚，适合网页阅读
- 原始资料中的中日英关键词必须尽量保留
