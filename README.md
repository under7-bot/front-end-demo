# front-end-demo

Google Classroom 学科资料详情页总览与 AI 记忆宫殿型学习导航。

这个项目是一个纯静态前端学习站点，包含：

- Google Classroom 学科资料总览
- 各科目知识路线
- 思维导图式板块导航
- 板块深度导览
- 中日英关键词对照
- Python / hardware 等基础详情页

## 入口

打开根目录的 `index.html` 会自动跳转到：

```text
classroom-study-pages/classroom-index.html
```

## 技术约束

- HTML
- CSS
- JavaScript
- 无后端
- 无数据库
- 可通过 GitHub Pages 发布

## 手机预览

在本机运行：

```powershell
node share-server.js
```

然后用手机访问同一 Wi-Fi 下的电脑 IP。
