ハードウェア基礎理論

把课堂资料中的基数转换、信息单位、2进制四则运算整理成 FE 考试可直接复习的知识地图。

一句话理解

本章的核心是理解计算机如何用 0 和 1 表示数据，并能熟练完成进制转换、单位换算和二进制运算。

考试核心知识

二进制与基数

基数是“几个进一位”。2进制只使用 0 和 1，适合硬件用电压高低、开关状态表示。

base radix

基数转换

2进制转10进制看权重并相加；10进制转2/8/16进制用除法取余并倒读。

重み 余り

8进制与16进制

2进制转8进制从右起3位一组；转16进制从右起4位一组，A 到 F 对应 10 到 15。

8 = 2^3 16 = 2^4

小数与误差

2进制小数位权是 2^-1、2^-2、2^-3。有些10进制小数会变成无限循环2进制，产生丸め誤差。

丸め誤差

bit / byte / 单位

1bit 是一个 0 或 1，1byte = 8bit。K、M、G、T 有时按1000，有时按1024，考试以题干为准。

1B = 8bit 2^10 = 1024

二进制运算

加法重点是进位，减法重点是借位；左移 n 位相当于乘 2^n，右移 n 位相当于除以 2^n。

繰り上がり 繰り下がり

必须背的公式

  • n bit = 2^n 种状态
  • 无符号 n bit 范围 = 0 到 2^n - 1
  • 1 byte = 8 bit
  • 左移 n 位 = × 2^n
  • 右移 n 位 = ÷ 2^n
  • 传输时间 = 数据量 ÷ 传输速度

FE 易混点

256 和 255

8bit 有 256 种状态，但无符号整数范围是 0 到 255，因为从 0 开始编号。

1000 和 1024

通信速度常见 1000 进制，内存容量题常见 1024 进制；FE 题目优先看题干定义。

分组方向

2进制转8/16进制时，从小数点或最右侧开始分组，不够位时补 0。

记忆宫殿路线

从玄关的 0/1 按钮出发，经过鞋柜权重、走廊除法机器、电视 3位/4位分组、厨房 bit 饭团、冰箱 1000/1024，再到洗手台进位和床上左右移位。按这条路线复习，整章会自然连起来。
