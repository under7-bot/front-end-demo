AI总结

网络基础的主线是：设备先有 IP 地址，域名通过 DNS 找到地址，路由器决定转发路径，TCP/IP 规定数据如何可靠传输。

疑问 / 易错点

  • 把 DNS 当成网站本身，而不是名称解析服务。
  • 认为路由器只负责 Wi-Fi，忽略它的转发作用。
  • 把 IP 地址和 MAC 地址混淆。
