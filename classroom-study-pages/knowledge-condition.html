一句话解释

条件判断让程序根据 true/false 选择不同执行路径。

知识走廊

变量→条件判断→循环

核心内容

if 会先计算条件式。条件为真时执行 if 块，否则执行 else 或跳过。

最小例子

if score >= 60: print('合格') else: print('不合格')
